# independent-projects

Welcome! This repository serves as a centralized portfolio for my independent software projects, utility scripts, and programming experiments. It tracks my self-directed development work outside of my structured coursework.

The focus of this repository is on building functional applications, exploring software architecture, and practicing clean code principles.

## Environment & Setup

Most programs in this repository run on standard Python. To execute a script locally:

1. Clone this repository.
2. Navigate to the project directory.
3. Run the file using the terminal:

```bash
python filename.py
```

## Folders

Here is how I have organized my files based on when I made them:

### 📁 1. 01_programming_basics/
My first programs covering inputs, basic variables, simple math, and basic loops.
* **simple_calculator.py:** A basic calculator program.
* **largest_of_three.py:** Compares three inputs to find the biggest one.
* **factorial_finder.py & fibonacci_sequence.py:** Math sequences with loops.
* **score_average_validator.py:** Takes scores, checks if they are valid, and finds the average.

### 📁 2. 02_data_structures/
Working with lists, tuples, and dictionaries to manage groups of data.
* **tuple_max_search.py:** Searches a tuple for the highest number.
* **list_prime_extractor.py:** Finds the prime numbers in a list.
* **word_frequency_counter.py:** Counts how many times words appear in a sentence.
* **shopping_cart.py:** A dictionary-based cart that tracks prices and items.

### 📁 3. 03_oop_foundations/
My first steps into Object-Oriented Programming (OOP) using classes, objects, and inheritance.
* **employee_salary_manager.py:** Modifies employee objects.
* **vehicle_fuel_types.py:** A simple example of inheritance with vehicle types.
* **shape_area_calculator.py:** Finding areas of different shapes using polymorphism.

### 📁 4. 04_oop_projects/
Larger, interactive console apps that use OOP concepts together.
* **employee_management_system.py:** A text-based system to add, search, and delete employees.
* **abstract_oop_calculator.py:** A calculator built using Abstract Base Classes (ABCs).

### 📁 5. 05_recursion_and_algorithms/
More complex topics like functions calling themselves and standard search algorithms.
* **recursive_palindrome_checker.py:** Checks if a word is spelled the same backwards recursively.
* **recursive_max_finder.py:** Finds the biggest number in a list using recursion.
* **recursive_binary_search.py:** A fast search algorithm for sorted lists.
